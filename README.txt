GEOHIDRANTES — BOMBEROS VOLUNTARIOS DE LOS REALEJOS

Esta carpeta contiene una PWA de prueba con los 709 hidrantes del KML.

PARA PUBLICARLA GRATIS:
1. Crear una cuenta en GitHub.
2. Crear un repositorio nuevo (por ejemplo: geohidrantes).
3. Subir TODOS estos archivos: index.html, data.js, manifest.json y sw.js.
4. En Settings > Pages, activar Pages usando la rama main y carpeta /root.
5. GitHub dará una dirección web.
6. Abrir esa dirección desde Android/iPhone.
7. En Android: menú del navegador > Instalar aplicación / Añadir a pantalla de inicio.
8. En iPhone: Compartir > Añadir a pantalla de inicio.

IMPORTANTE:
- La geolocalización normalmente requiere HTTPS; GitHub Pages proporciona HTTPS.
- Esta es una versión inicial. Antes de uso operativo conviene revisar los estados de los 709 hidrantes y añadir autenticación/actualización de datos.
